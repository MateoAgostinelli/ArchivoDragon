## Vision

### 10x Check
El archivo de referencia del Dragón: no una página de hincha más, sino la infraestructura de memoria del club. Todo el contenido histórico (1906-hoy) estructurado como dataset con fuente citada y copia archivada; las vistas (timeline, máquina del tiempo, tal-día-como-hoy, cancionero con audio, stats) emergen de la misma base. La comunidad aporta material y el archivo sobrevive a cualquier plataforma porque vive en Git + páginas estáticas + Wayback.

## Accepted Scope (added to this plan)
- Vista "Tal día como hoy" autogenerada del dataset (con fallback "pieza más cercana" para días vacíos)
- Máquina del tiempo navegable por fecha + schema v2 de `partido` (rival, resultado, torneo, formación)
- Canal de aportes: **Google Form** (decidido D19 — fricción mínima para hinchas no técnicos), respuestas a planilla del builder, link visible en el sitio; revisión manual semanal
- Página /stats: piezas por década/tipo, fuentes más citadas, últimas agregadas, huecos
- Cancionero con audio embebido (YouTube) donde exista, con link archivado como respaldo de la CITA (ojo: Wayback no preserva el video reproducible — el respaldo preserva la referencia, no el sonido)

Base ya aprobada en el design doc (aún sin construir): schema v1 con `source` obligatorio + scraper Python + batch Wayback reanudable + sitio Astro (timeline, listado por tipo, detalle, Pagefind) + deploy Cloudflare/GitHub Pages. El repo git propio ya existe (creado en esta sesión).

### NOT in scope (considerado y explícitamente fuera)
- Galería de fotos con copias locales (etapa 2, tras política de derechos de imagen)
- RSS/newsletter, dominio propio, audio propio de tribuna (diferidos, ver abajo)
- CMS, base de datos, backend, login (rechazados por diseño: estático + Git es la arquitectura)
- Wiki editable por terceros (la colaboración entra por Form + curaduría, no edición directa)

### What already exists (se reutiliza)
- Astro content collections + Pagefind (sitio y búsqueda), Wayback Save API (preservación), GitHub Actions (cron diario, link rot, CI), Python del builder (scrapers). No se reinventa nada.

### Dream state delta
Este plan deja el sistema a un paso del ideal de 12 meses: toda la infraestructura del archivo construida y publicada, con el contenido como único gradiente (cargar piezas activa progresivamente timeline → tal-día → máquina del tiempo). Falta para el ideal: galería con derechos, audio de tribuna, comunidad aportando — todo montable sobre esta base sin re-arquitectura.
